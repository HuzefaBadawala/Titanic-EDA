# Titanic Dataset: Exploratory Data Analysis (EDA)

A beginner-friendly Python EDA project using the Titanic passenger dataset.

## Project contents

- `Titanic_EDA.ipynb` - Jupyter Notebook containing data loading, cleaning, summary tables, visualizations, and conclusions.
- `titanic.csv` - Original CSV dataset supplied for this project.
- `titanic_cleaned.csv` - Cleaned dataset generated by running the notebook.
- `requirements.txt` - Python dependencies.
- `.gitignore` - Common files excluded from version control.

## Analysis included

1. Dataset inspection and missing-value checks.
2. Numerical summary statistics.
3. Categorical summary statistics.
4. Age distribution histogram.
5. Survival-rate bar chart by gender.
6. Correlation heatmap for numerical variables.
7. Markdown conclusions for each visualization and an overall conclusion.

## Data cleaning

The supplied CSV contains missing values. The notebook keeps the original `titanic.csv` unchanged and creates a cleaned DataFrame by:
- Filling missing `Age` values with the median.
- Filling missing `Embarked` values with the mode.
- Replacing missing `Cabin` values with `Unknown`.
- Removing duplicate rows.

The cleaned data is saved as `titanic_cleaned.csv` when the notebook is run.

## Requirements

- Python 3.9 or later recommended
- Jupyter Notebook or JupyterLab

Install dependencies:

```bash
pip install -r requirements.txt
```

## Run the project

1. Clone or download this repository.
2. Open a terminal in the project folder.
3. Install the dependencies using the command above.
4. Start Jupyter:

```bash
jupyter notebook
```

5. Open `Titanic_EDA.ipynb`.
6. Run all cells from top to bottom.

Keep `titanic.csv` in the same folder as the notebook.

## Dataset notes

The supplied dataset has 891 rows and 12 columns. The target column `Survived` uses:
- `0` = Did not survive
- `1` = Survived

The correlation heatmap excludes `PassengerId` because it is an identifier, not a meaningful measurement. Correlation indicates association, not causation.

## Tools used

Python, Pandas, NumPy, Matplotlib, Seaborn, and Jupyter Notebook.
